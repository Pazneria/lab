# Hearth & Herb

A small first-person 3D cottage: kitchen, magical workroom and greenhouse. The scene is self-contained apart from the installed Three.js and Vite npm dependencies. All meshes, textures, furnishing and plant shapes are made procedurally in `main.js`.

## Launch

From this directory, with Node.js installed:

```powershell
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
```

Open the **suggested launch address** http://127.0.0.1:5179/ in a desktop browser. This address is not a running preview. If dependencies are missing, run `npm ci` first. The `dist/` directory is a production build generated by `npm run build`.

## Controls

- Click **Enter the cottage**, then move the mouse to look.
- **W A S D** or arrow keys move; hold **Shift** to move faster.
- **R** or the Reset button returns to the entrance.
- **Esc** releases the pointer; click the scene to capture it again.

## Checks and limitations

`npm run build` and `node --check main.js` passed. `node check-route.mjs` checks connectivity in the collision model for the entrance, kitchen, workbench, shelves, greenhouse and return. No browser, server, screenshot, GPU test or performance benchmark was launched during this build. Consequently, visual appearance, interactive controls, actual collision feel, and frame times have not been verified in a browser. The scene uses fixed lighting and simple collision volumes; there are no moving spells, doors, or touch controls. Translucent panes and glass objects use ordinary alpha blending rather than physically simulated refraction.

See `run-record.txt` for timestamps and process history.
