# October 19 benchmark gallery source review

The gallery now has **89 direct cards in 60 graph families**. A new [WebDev Arena Frontend view](../results.html?benchmark=webdev-arena-frontend-2026-10-18) plots the first 20 displayed rows of the primary source's October 18 table. That table reports 147 models and 790,403 total votes. The complete 142-row October 8 table remains a separate, directly accessible card. The new selection is a dated snapshot, not a complete updated leaderboard or a before/after improvement experiment.

The first five October 18 preference ratings are Claude Opus 5.5 (Max) 1848 ±17, Claude Sonnet 5.5 (xHigh) 1808 ±15, GPT-6 Astra (Max) 1797 ±11, Claude Fable 5.1 (Max) 1776 ±10, and GPT-6.1 Sol (Max) 1768 ±15. The source publishes score ranges but does not establish their confidence coverage in the table. Each row retains its own vote count and preliminary flag; the page-wide total is not a sample size for a row. Model effort is copied only when explicit in its name. Exact per-row tool budget, harness version, task cost, task time, run date and model release date are unavailable. API list prices are not treated as evaluation cost. Source: [Arena's dated Frontend table](https://arena.ai/leaderboard/code/webdev/frontend).

These measures answer different questions:

| Source | Question and current gallery status |
| --- | --- |
| [WebDev Arena Frontend](https://arena.ai/leaderboard/code/webdev/frontend) | Human website preference. A selected October 18 cohort is plotted beside the preserved complete October 8 cohort. Its Frontend, Fullstack and technology/domain filters must not be pooled. |
| [DesignArena](https://www.designarena.ai/about) | Anonymous four-model design tournaments and five pairwise votes yield Bradley-Terry preference ratings. Overall Frontend, Website, Web Apps, Fullstack and Image to HTML are separate. Dynamic model-page values changed during review and the all-category tournament total is not a Website sample size, so no new category score was imported. |
| [Design2Code](https://github.com/NoviScl/Design2Code) | Screenshot-to-code fidelity on 484 C4 pages, with a separate HARD 80. Visual/CLIP, element, text, position and color dimensions and prompt methods remain separate historical views; no new frontier score was verified. |
| [FrontendBench](https://arxiv.org/abs/2506.13832), [WebGen-Bench](https://arxiv.org/abs/2505.03733), [CATTest](https://arxiv.org/abs/2609.00081) | FrontendBench has 148 prompt/test pairs, and WebGen-Bench reports 647 interaction tests for generated websites. Harness details, including [Harbor's WebGen adapter](https://github.com/harbor-framework/harbor/blob/main/adapters/webgen_bench/README.md), matter for comparisons. CATTest's 102 annotated apps assess bug discovery by test agents, not website generation quality. No current commensurate frontier functional-completion cohort was found for a new graph. |

The [Bench2Drive 0.0.4 source](https://github.com/Thinklab-SJTU/Bench2Drive/blob/0.0.4/README.md) confirms an August 6 release with 1,100 uniform **training** routes and a separate 220-route validation benchmark. The gallery already plots its 0.0.4 LEAD and Simlingo outcomes (Driving Score 95.59/86.55 and route success 87.28%/70.45%); no duplicate result was added. Individual system run dates remain unavailable. The [BEHAVIOR 2026 challenge](https://behavior.stanford.edu/challenge/index.html) has 100 tasks in seven scenes; submissions closed October 16 and winners are scheduled for November 4. [Baseline instructions](https://behavior.stanford.edu/challenge/baselines.html) require v3.9.3. Its guide remains source-only without an announced winner score.

The clinical sources support careful cohort labels rather than a new score. [HealthBench Professional](https://openai.com/index/making-chatgpt-better-for-clinicians/) covers care consult, documentation and medical research, and distinguishes base models from the ChatGPT for Clinicians tool system. [MentalHealthBench](https://openai.com/index/introducing-mentalhealthbench/) uses synthetic conversations, expert-consensus criteria and GPT-5.6 Sol automated grading; its newest-provider comparison is dated September 23. Existing maximum- and default-effort views remain separate. These results are benchmark observations, not clinical outcomes.
