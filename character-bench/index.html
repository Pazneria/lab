How this comparison works

Only two distinct, verified attempts of the exact same prompt can be paired. A/B order is randomized. Each character is centered and fitted to the same unit bounding sphere without rewriting its frozen GLB; this compares framing rather than physical size.

The original PBR materials are preserved. Clay and wireframe are optional inspection modes. White studio lights, exposure, environment and the movable key light are shared across both views. Submitted lights and animations do not run. A rig is optional.

Drag to rotate; scroll or pinch to zoom. With a view focused, arrow keys rotate, +/− zoom, and Home resets. Each view also has Front, Back and Close-up controls. Model labels remain hidden until both files load and you choose a preference. Swap A/B starts a fresh inspection with linked cameras, original materials and the default shared light. It is available before choosing. Escape in an expanded view restores both panes. Votes are saved in shared storage and persist across reloads. Each browser credential has one current judgment per entry pair. Change preference replaces it; Withdraw removes it from ratings; Skip records no vote.

Labels are hidden as an interface convention. The featured Lab character may be recognizable, and static source files expose provenance; this is not a fully blinded experiment.

Frozen asset hashes are verified before import. A failed import stays outside voting. Source timings and infrastructure limits are shown after a confirmed preference. Public pairwise ratings are separate from those source disclosures and from uncollected numeric rubric scores.
