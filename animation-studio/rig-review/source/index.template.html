How to review
Drag to orbit; Shift-drag to pan; wheel to zoom. Click a displayed joint dot to select it, or select any node in the tree. Seconds/phase fields pause playback, and arrows step one 30 Hz sample. All distances use authored units. Contact lanes are prior authored labels, not a new contact solve; the default in-place view does not prove planted world contact. For the exact prior-human clips only, optional reference travel applies +Z referenceSpeed × seconds once to mesh, actual nodes, sockets and markers over the fixed grid. It stops at one cycle; it is a straight-level numerical proof fixture. Green/orange polygons use all six actual exported sole points per foot and half-open authored contact labels, with no new contact solve or quality acceptance.
